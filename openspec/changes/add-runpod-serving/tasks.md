# Tasks

The implementer tier follows the model-routing skill:
- **[Opus]:** hard or ambiguous work.
- **[Sonnet]:** fully specified, pattern-following work.
- **[Human]:** needs a person: the Runpod account, keys, billing, legal review, or a GPU session.

Design decisions are referenced as D1–D9 (design.md). Nothing in groups 1–4 and 7–8 needs a GPU or a Runpod account; those groups run on the dev box with recorded responses, like the rest of the harness tests.

- [ ] 3.2 [Sonnet] Cold-start retry and request size guard: in `VllmClient.chat` and `PipelineClient.layout`, when a 502/503 or a "no workers available" body arrives within `wait_ready_s` of the client's creation, retry with 5 s backoff until the budget ends instead of counting it as the single retry; before sending, compute the JSON body size and return a `CallResult(error="request 31.2 MB exceeds 25 MB")` without sending when it exceeds `max_request_mb` (constructor argument, default 25). Verify tests for the cold-start retry sequence, the normal single-retry path unchanged, and the oversized page producing an error row in `PlannedModel.predict`.
- [ ] 3.3 [Sonnet] In `ocr_bench/cli.py`: `_write_infer_config` records `endpoint_kind` (`runpod` when the host ends with `api.runpod.ai`, else `self_hosted`) and, when `/version` is unreachable on a Runpod endpoint, the vLLM version from the model's latest `configs/runpod/releases.yaml` record; add `ocr_bench/runpod/releases.py` with `load_releases()`, `latest(model)` and `append(record)` that refuses a record containing a string matching `rpa_[A-Za-z0-9]{20,}` or `[a-z0-9]{10,}\.api\.runpod\.ai`. Verify tests for the kind detection, the version fallback and the refusal.
- [ ] 3.4 [Sonnet] Client-data guard in `cli._connect`/`infer` (D9): when any selected manifest row has `source == bankstmt` and a model's base URL is a Runpod host, look the endpoint up in `.runpod/state.yaml` (`ocr_bench/runpod/state.py`: `load_state()`, `endpoint_for_host(host)`) and exit 2 naming the model and endpoint name unless `client_data: true`; the parity and smoke commands skip the guard because their sets contain no client data.
